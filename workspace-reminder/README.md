# Workspace Reminder

Separate Android reminder app for work tasks.

### V1
- Time/date reminders with local notifications
- Daily and weekly repeat
- Location reminder foundation with Android background geofencing
- Today / Upcoming / All views
- Done and delete actions
- Offline local storage
- System light/dark theme

The Android project is generated by the GitHub Actions workflow so the repository stays isolated from the existing Unique Market Service app.

Location reminders require Android location permissions, including background location on supported Android versions. For reliable geofencing, keep location enabled and review battery-optimization settings.
